What is a database?

A database is an organized collection of data. A database management system (DBMS) is software used to create, maintain, protect, and access that data. Businesses, schools, hospitals, and websites use databases to keep information available and organized.

For example, a college database might store student records, course information, and class registrations. Instead of keeping separate lists that are difficult to maintain, related information can be stored in connected tables.

Relational and NoSQL databases

Relational databases

Relational databases organize information into tables made of rows and columns. Tables can connect through keys, which helps reduce repeated data and maintain relationships. SQL is commonly used to query and manage relational data.

Examples include PostgreSQL, MySQL, and Microsoft SQL Server.

NoSQL databases

NoSQL databases use models such as documents, key-value pairs, graphs, or wide columns. These designs can be useful when data does not fit neatly into a fixed set of tables or when an application needs a particular scaling approach.

MongoDB and Redis are examples of NoSQL database systems.

Basic database terms

  • Table: A structure that stores related records.
  • Row: One record in a table.
  • Column: A field that describes one type of information.
  • Primary key: A value that uniquely identifies a row.
  • Query: A request to retrieve or change data.

Good database design helps keep information accurate, reduces unnecessary duplication, and makes it easier for applications to find the data they need.
